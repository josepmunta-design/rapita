## Descripció documentada

- La comunitat s’havia traslladat a Tortosa a finals del XVI; els edificis continuaven amb colons, criats i usos agraris. El lloc no era deshabitat el 1780. [N112](../fonts-20261031/originals/N112.pdf) · p.196–199
- La llegenda de novembre de 1780 esmenta una casa vella de les monges per als guardes de sanitat i dues cases reials dels assentistes que serveixen per al canal. Aquesta manzana no s’ha de confondre amb la Mançana antiga del nord. [N029](../fonts-20261031/originals/N029.jpg) · punt 3; [N112](../fonts-20261031/originals/N112.pdf) · p.202–203
