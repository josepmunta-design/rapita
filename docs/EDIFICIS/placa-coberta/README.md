## Descripció documentada

- Plaça coberta molt avançada amb edifici superior i façana dòrica simètrica al temple; gran tinglado annex. [N112](../fonts-20261031/originals/N112.pdf) · art.9 p.231
- El 1869 un pati núm.8 es descriu amb parets fins al primer pis i 210,160 m², comprat per Julio Carballo. L’article n’estableix identificació probable. [N112](../fonts-20261031/originals/N112.pdf) · p.214–215
