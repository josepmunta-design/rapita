## Descripció documentada

- Jardí amb bones reixes fet per un particular en benefici de les obres, associat a concessió de 200 jornals i lloguer franc. [N112](../fonts-20261031/originals/N112.pdf) · art.14 p.232
- Terra aportada de devesa i horts de les monges; reclamació en procés 1796. La carta de 24/9/1829 delimita dues cases amb Sant Antoni, jardí botànic, casa del conservador i plaça. [N112](../fonts-20261031/originals/N112.pdf) · p.217–218
- El plànol atribuït a Gorría de finals del XIX encara el representa; no determina les espècies exactes. [N112](../fonts-20261031/originals/N112.pdf) · il·l.9 p.218
