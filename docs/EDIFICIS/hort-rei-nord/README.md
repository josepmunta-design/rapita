- Dues peces simètriques a l’entrada de València, terrenys sobre roca millorats amb terres transportades, reixes, regadores i desguassos. Una sínia abundant subministra obra i horts. [N112](../fonts-20261031/originals/N112.pdf) · art.10 p.231 i p.215–216
