## Descripció documentada

- Comprat el 1792 per Josep White de Benicarló per 14.000 rals de billó amb compromís d’igualar l’altre edifici. [N112](../fonts-20261031/originals/N112.pdf) · p.217
- El 1794 les obres continuen a càrrec del comerciant; la font no enumera per separat tots els acabats o la coberta. [N112](../fonts-20261031/originals/N112.pdf) · art.13 p.232
