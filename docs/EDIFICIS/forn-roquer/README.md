## Descripció documentada

- El model 0.12 representa un forn de maons sobre la base de les obres auxiliars revisades a la tesi. No és prova que el forn de pa de les casetes de 1781 i el Rajolar de dos forns fossin aquesta mateixa peça. [ANT-LIT](../../ROQUER_CANAL.md) · fonts i annexos del Roquer
- La nova carpeta documenta un Rajolar de dos forns i casa a la Rabosa, amb referència retrospectiva cap a 1786. Cal conciliar establiments abans d’afegir-ne tots els cossos. [N112](../fonts-20261031/originals/N112.pdf) · p.223–224
