## Descripció documentada

- Hort d’uns tres jornals amb pou de sínia, bassa, regadores i arbres davant la masia de les monges abans del 1780. [N112](../fonts-20261031/originals/N112.pdf) · p.198
- Cova gran habitada per pagesos, mariners, obrers i puntualment tropa; l’article en ressegueix usos fins a refugi durant la Guerra Civil. No indica una cavitat excavada mètricament. [N112](../fonts-20261031/originals/N112.pdf) · p.198
