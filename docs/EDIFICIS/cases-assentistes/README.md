## Descripció documentada

- La carta d’agost de 1780 proposa comprar ferreria i altra caseta dels assentistes per fusteria, ferreria i magatzem del canal; la llegenda de novembre parla de dues cases construïdes a compte del rei. Cal explicar aquesta diferència administrativa abans de comptar cossos. [N025](../fonts-20261031/originals/N025.jpg) · fitxer o imatge completa; [N026](../fonts-20261031/originals/N026.jpg) · fitxer o imatge completa; [N029](../fonts-20261031/originals/N029.jpg) · punt 3
- El 1794 hi ha casutxes embargades als assentistes dins dels 38 registres privats mixtos. [N112](../fonts-20261031/originals/N112.pdf) · art.5
