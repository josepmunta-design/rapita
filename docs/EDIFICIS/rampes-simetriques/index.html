Dues rampes del Cóc

El document conserva testimonis de diverses èpoques. Una data de fotografia o inventari no equival a la data de construcció. Les coordenades i dimensions del prototip es mantenen separades de l’evidència.

Col·locació

Una del Cóc per l’àmbit posterior de Sant Miquel cap a la dàrsena petita; altra corbada per l’inici de Sant Francesc i Mare de Déu de Montserrat cap a Fonda Vella i dàrsena gran. Corredors interpretats, no cotes aixecades.

Certesa documental: B relacional / C mètrica.
