## Descripció documentada

- Concessió de 1782 amb quatre afrontacions:30 vares 1 peu 2 polzades;60 vares 1 peu;38 vares 1 peu;56 vares 1 peu 6 polzades castellanes. [N112](../fonts-20261031/originals/N112.pdf) · p.211
- L’article dona equivalències 25,30 m,50,30 m,32,22 m i 47,34 m: són costats de la finca, no amplades de les dues cases ni una planta rectangular resolta. [N112](../fonts-20261031/originals/N112.pdf) · p.211
- El plànol de 1782 representa un recinte amb pati; no determina la distribució interior de cadascuna de les dues cases. [N112](../fonts-20261031/originals/N112.pdf) · il·l.2 p.204
