## Descripció documentada

- Aquest número identifica un cos del model actual. No és una numeració cadastral ni identifica una casa documentalment. Els testimonis i fases del tipus es reprodueixen aquí com a context compartit, sense verificar-ne la correspondència individual. [N112](../fonts-20261031/originals/N112.pdf) · art.1–4 p.230–231
- Catorze cases amb murs a cota d’embigar terrats, primer pis embigat i pòrtics del front conclosos. [N112](../fonts-20261031/originals/N112.pdf) · art.3 p.230
- Deu cases rodones ofertes a venda en edicte 19/9/1794; cinc arcs centrals per cada costat del semicercle segons la interpretació de l’autora. Les quatre restants no s’han de repartir automàticament dues i dues. [N112](../fonts-20261031/originals/N112.pdf) · p.210 nota 60
- N031 és una postal amb fusta i arcs de la galeria; N074 és una recreació amb nom ChatGPT i no és prova independent. N102/N103 són versions de la mateixa vista, una acolorida.
