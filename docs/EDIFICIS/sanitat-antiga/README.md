## Descripció documentada

- Guardes de sanitat vivien prop del convent abans de 1780; la llegenda els situa a la casa vella de les monges. [N029](../fonts-20261031/originals/N029.jpg) · punt 3; [N112](../fonts-20261031/originals/N112.pdf) · p.198 i 202
- El punt 4 del plànol de 1782 es llegeix com casa de Sanitat. La relació amb l’oficina a cap de moll de 1794 encara s’ha de demostrar. [N112](../fonts-20261031/originals/N112.pdf) · p.203–204 i 220
