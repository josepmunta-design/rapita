## Descripció documentada

- La carta d’agost 1780 proposa utilitzar les cases comprades per a fusteria, ferreria i magatzem del canal. [N025](../fonts-20261031/originals/N025.jpg) · primera cara
- L’article 5 inclou fusteria antiga dins el conjunt privat mixt. L’article 7 situa una fusteria al front de la Mançana; no s’ha de concloure sense prova que siguin dos tallers simultanis o un trasllat. [N112](../fonts-20261031/originals/N112.pdf) · art.5 i 7 p.231
